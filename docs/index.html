安装后在设置里导入你自己的词典 PDF。发声选「微软 Edge 语音」即可直接试听。本地 CosyVoice 再用「一键下载权重」，文件较大，中断后可以再点一次继续。

  1. 01
    点读点词卡或页面上的词。第一次合成后可以再听，不必重新生成。
  2. 02
    中英讲解释义、例句和场景中英文对照。讲解可以整段朗读，也可以下载成一条 WAV。
  3. 03
    历史点读和讲解都会留下记录。之后从历史里打开，就能再播一次。
  4. 04
    两种声音设置里可选微软 Edge 语音，或本机 CosyVoice。Edge 不用下载模型。CosyVoice 3：Hugging Face · 镜像。CosyVoice 2：Hugging Face · 镜像。
